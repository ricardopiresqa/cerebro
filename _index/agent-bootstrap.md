# Agent Bootstrap

Documents an AI agent should read when starting a session in this vault.

## Required Reading

1. `README.md` — vault overview and structure
2. `_index/cerebro-quickstart.md` — how to use this vault
3. `1_projetos/<project>/CONTEXT.md` — project context
4. `1_projetos/<project>/DECISIONS.md` — past decisions
5. `1_projetos/<project>/CURRENT.md` — current state

## Session End

6. Log session in `sessoes/`
7. Update `CURRENT.md` with next steps
8. Update `DECISIONS.md` if new decisions made
